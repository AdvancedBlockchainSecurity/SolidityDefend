## How to Run a Baseline Scan

Use the committed script — it builds the binary, runs the tool's own
`--validate` ground-truth harness plus a clean-FP check and per-target census,
and enforces the recall/clean-FP invariants (non-zero exit on regression). It
relies on `--validate` and `-o` file output only, never on parsing the
banner-wrapped stdout, so results are deterministic.

```bash
scripts/baseline.sh          # human-readable report + invariant gate
scripts/baseline.sh --json   # machine-readable summary (version, recall, precision, FPs)
BIN=path/to/soliditydefend scripts/baseline.sh   # reuse a prebuilt binary
```

The historical inline snippet that scraped `-f json` stdout is deprecated: in
directory/project mode the tool prints a banner and a trailing summary around the
JSON, so a naive `json.loads` on stdout silently under-counts. `scripts/baseline.sh`
writes JSON via `-o` to a file and parses that instead.
